# История версий, выкатка, домен

## История версий

Запись это проза на двух языках: английский в `changelog.html`, русский в
`assets/i18n.js` под `cl.<версия без точек>.*`. Текст пишет человек, механизировано всё
вокруг:

```bash
node tools/changelog.mjs new 0.2.8 --date "10 September 2026"   # заготовка в обоих файлах
node tools/changelog.mjs check                                  # оба языка, порядок, без хвостов
node tools/changelog.mjs check --version 0.2.8                  # и запись именно об этой версии
```

`check` идёт на каждой выкатке. `release.yml` клиента CalliforniaDesktop чекаутит этот
репозиторий и запускает `check --version <тег>` до сборки: версия без записи не выходит.
Ворота нужны потому, что `privacy.html` обещает объявлять изменение в хранимом здесь до
того, как оно вступит в силу. Поэтому запись о выпуске клиента вливается в `main` сайта
раньше тега.

## Выкатка

Push в `main` запускает `.github/workflows/deploy.yml`: `tools/check-css.js`,
`tools/changelog.mjs check`, затем корень репозитория целиком уходит на GitHub Pages.
Первичная настройка: Settings, Pages, Source = GitHub Actions. Окружение `github-pages`
может требовать подтверждения ревьюера.

## Домен

Сайт отдаётся с `callifornia.online`. Файл `CNAME` в корне привязывает выкатку к домену:
он входит в публикуемое и должен оставаться в git, иначе следующая выкатка вернёт сайт на
`frontmany.github.io`.

DNS у регистратора:

| Имя | Тип | Значение |
|---|---|---|
| `@` | `A` | `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` |
| `www` | `CNAME` | `frontmany.github.io.` |

(Это адреса GitHub Pages для корня домена; при поддержке IPv6 добавить набор `AAAA` из
документации GitHub.) Когда записи разрешаются, включить Enforce HTTPS: сертификат Let's
Encrypt выдаётся сам. `api.callifornia.online` это шлюз бэкенда, запись `A` на его хост, к
Pages отношения не имеет.
