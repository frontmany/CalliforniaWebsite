# Оформление

Сайт говорит языком оформления самого приложения, а не отдельного бренда.

- **Палитра, шрифты и радиусы** это `resources/qml/Theme.qml` CalliforniaDesktop один к
  одному, в обеих темах. `assets/style.css` держит их токенами с теми же именами.
- **Фон** (`.backdrop`) это `components/ScreenBackdrop.qml`, перенесённый в CSS: акцентная
  заливка сверху, тусклее из правого нижнего угла и точечная сетка DotGrid 22 px поверх.
  Квадратичное затухание заливок как в приложении, поэтому у большого круга нет края.
- **Первый экран** повторяет `screens/HomeScreen.qml`: моноширинная надпись, крупный
  заголовок с отрицательным трекингом, тихая строка, действия и персонаж справа.
- **Макеты в строках возможностей** это куски настоящих экранов, каждый из названного
  QML-файла: поле входа из `screens/HomeScreen.qml`, строка списка людей из
  `components/PeopleScreen.qml`, номер безопасности из `components/SafetyNumberDialog.qml`
  (две половины по тридцать цифр, шесть групп по пять). Когда экран меняется, макет
  сверяется с ним. Картинки идущего звонка нет намеренно.
- **Каждый глиф это `Icons.qml` путь в путь**: тот же атрибут `d`, бокс 24, штрих 1,75 с
  круглыми концами. Исключение одно, стрелка загрузки: в приложении ничего не качают
  руками, поэтому своей стрелки у него нет, она нарисована по той же спецификации.
  Плитка про допуск компьютера носит `shieldCheck`, как `PairingDialog.qml` в этот момент;
  «Нечего продавать» носит `eyeOff`.
- **Подложки глифов** (`.tile-glyph`, `.panel-icon`) как в `PairingDialog.qml` и
  `CrashConsentDialog.qml`: скруглённый квадрат `accentSoft`, глиф в половину бокса (на
  сайте 34 px вместо 56).
- **Переключатель в шапке** это `components/SegmentedToggle.qml`, и он один, для языка.
  Тема не выбирается: её отвечает `prefers-color-scheme` в стилях, без переключателя,
  без сохранённого выбора и без скрипта до первой отрисовки.

Правила текста те же, что в приложении: без символа `·`, без тире и двоеточий в тексте
для посетителя.

## Шрифты

IBM Plex лежит в `assets/fonts/` и объявлен в `assets/fonts.css`, а не берётся с Google
Fonts. Это решение о приватности: ссылка на `fonts.googleapis.com` отдала бы адрес
каждого посетителя третьей стороне за пределами России, а политика обещает, что этого
нет. Восемнадцать файлов (latin, latin-ext, cyrillic, шесть начертаний), посетитель
качает только нужные подмножества. Лицензия SIL OFL 1.1, `assets/fonts/OFL.txt` обязан
оставаться в git.

Новое начертание: взять стили Google современным user agent, оставить `latin`,
`latin-ext` и `cyrillic`, скачать `woff2` рядом и добавить `@font-face` с тем
`unicode-range`, что дал Google: без диапазонов каждый браузер качает все файлы.

## Персонаж и знак

`assets/mascot-*.webp` это рисунки с главного экрана приложения
(`resources/images/doggy*.png` CalliforniaDesktop, один персонаж в восьми позах). На сайте
по одной позе на место:

| Файл | Поза | Где |
|---|---|---|
| `mascot-wave.webp` | подмигивает, лапа вверх | главная |
| `mascot-hi.webp` | лапы вверх, радуется | страница входа, ссылка годна |
| `mascot-oops.webp` | ахает, лапы на щеках | страница входа, ссылка сломана или открыта на телефоне |
| `mascot-sit.webp`, `mascot-cheer.webp` | сидит с косточкой, звёзды в глазах | пока нигде |

Новая поза: PNG из приложения, обрезать прозрачные поля, длинную сторону до размера на
странице (около 700 px на главной, 460 px в остальных местах), WebP с качеством около
88. Исходники в 3 или 4 раза больше, чем показываются, отдавать их как есть нельзя.

Знак так же: страницы грузят `assets/logo-mark.webp` (96 px) и `logo-mark@2x.webp`
(192 px), полный `logo.png` остаётся для `og:image` и для писем Auth, которые берут его
по этому адресу.
