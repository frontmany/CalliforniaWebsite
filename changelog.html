Changelog

Every release, in order. The app applies these updates automatically — this page is here so you can see what changed and when.

v0.1.0

9 August 2026

Chat, presence and a space with every friend

  • Chat inside a call, kept with the call, so it is still there the next time you open it
  • Live presence for friends, including «waiting for you» when someone is sitting in a space you share
  • A private space with every friend, opened from their row or from a pin on the home screen
  • Friend requests and profile changes arrive without a refresh
  • Settings became a screen of its own

The way a call is joined changed, so installs older than 0.1.0 update themselves.

v0.0.15

7 August 2026

An honest camera

  • Turning the camera on now succeeds only once a camera has actually opened, so a missing or busy one says so instead of lighting the button and sending nothing
  • The camera button dims when there is no camera, and the keyboard shortcut follows the same rule

v0.0.14

7 August 2026

Wayland screen sharing stays alive

  • The share reached streaming and died within milliseconds, because starting the capture tore down the very session it was about to read. It no longer does.

v0.0.13

7 August 2026

Wayland screen sharing, delivered

  • Carries the fix from 0.0.12, which never shipped because GitHub Actions was in a major outage
  • The chooser appears every time you start sharing, so you can pick a different window than last time
  • On Linux the update button no longer appears minutes before the package reaches the repository

v0.0.12

6 August 2026

The right order for Wayland

  • Sharing failed with «no target node available» because the PipeWire loop was started after the stream had already gone looking for its node. The loop now starts first.

This version never shipped. GitHub Actions was down while it was being built, so 0.0.13 carries the fix.

v0.0.11

6 August 2026

The portal session outlives its handshake

  • The share died the instant it was granted, because the connection that opened the session closed as soon as the handshake finished. It now lives as long as the share does.
  • The chooser is asked every time instead of remembering a source, so a second share cannot silently show the first window again

v0.0.10

6 August 2026

Finding the node the portal granted

  • Sharing on Wayland asked for permission, got it, and then produced nothing. The node is now named the way current PipeWire actually reads it.
  • Frames the app cannot read are reported once instead of being dropped in silence

v0.0.9

6 August 2026

Screen sharing on Wayland

  • Sharing on Wayland goes through your desktop's own chooser and PipeWire, instead of looking as though it worked while everyone else saw a black rectangle
  • A session that cannot be captured at all now refuses with a message, before anything is published
  • Linux package updates show the package manager's real output

v0.0.8

5 August 2026

Package updates that say what they are doing

  • The Linux in-app update shows progress, failure and the restart prompt, instead of looking as though nothing had happened for tens of seconds
  • The relaunch waits for the old process to exit, so a stalled shutdown no longer leaves you without a window
  • Both download buckets are pruned to the newest two versions

v0.0.7

5 August 2026

Linux window, icon and theme

  • The window has a title bar on GNOME again. The Wayland decoration plugin was missing from the packages, so the window came up bare and could not be moved.
  • The app icon shows up instead of a generic cog
  • A dark desktop no longer starts Calls in light mode on a fresh install
  • Tooltips wait longer before appearing

v0.0.6

5 August 2026

A re-cut of 0.0.5

  • The same app as 0.0.5. Its Linux job failed while signing the repository, after the update manifest had already gone out.

v0.0.5

5 August 2026

Calls on Linux

  • Packages in .deb and .rpm, with a signed APT and YUM repository for updates
  • Microphone through PulseAudio, camera through V4L2, screen sharing on X11
  • Updates in one click through your package manager
  • A redesigned home screen and navigation
  • Wayland screen sharing came later, in 0.0.9

v0.0.2

2 August 2026

A clean uninstall

  • Uninstalling removes the install directory, your data and the updater's leftover startup entry. New installs only.

v0.0.1

2 August 2026

First release

Hello, world

  • Group video meetings with short, shareable meeting IDs
  • Friends list, add people once and call them with one click
  • In-app invites, see who invited you and join right from the app
  • Screen sharing with a window or full-screen picker
  • Light and dark themes
  • Background auto-updates, signed, differential, applied on one restart
  • Per-user installer for Windows 10/11, no administrator rights required
